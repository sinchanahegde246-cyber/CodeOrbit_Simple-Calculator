# Simple Calculator

A Python command-line calculator for the CodeOrbit Tech Python Programming Internship.

## Features
- Addition, subtraction, multiplication, and division
- Reads two numbers from the user
- Uses `try/except` for invalid number input
- Handles division by zero
- Includes comments and a reusable function

## Run
Open the folder in VS Code, choose **Terminal → New Terminal**, and run:
`python simple_calculator.py`
On Windows, try `py simple_calculator.py` if needed.

## Tests
Try 10 and 5 with each operation. For division by zero, choose division and enter 0 as the second number. Also test letters instead of a number.
